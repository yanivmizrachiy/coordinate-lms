# מדיניות פרטיות יישומית

> מסמך הסבר בלבד. `RULES.md` הוא מקור האמת היחיד.

- תרגול ללא הרשמה אינו מיועד לייצר פרופיל תלמיד, דוח כיתתי או מעקב מרכזי.
- רק לאחר הרשמה והתחברות נשמרים תוצאות, ניסיונות, זמן פעילות והתקדמות לצורך דוחות אישיים ודשבורד מנהל.
- בעמוד הראשון יש להציג לתלמיד לפני הרשמה הסבר ברור על ההבדל בין תרגול חופשי לבין תרגול מתועד.
- יש לאסוף רק פרטים שנקבעו במקור האמת ולהגן עליהם באמצעות Firebase Authentication וכללי Firestore.
