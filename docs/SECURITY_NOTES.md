# אבטחה — הערות יישום

> מסמך הסבר בלבד. `RULES.md` הוא מקור האמת היחיד.

- אימות משתמשים בייצור מתבצע באמצעות Firebase Authentication.
- אין לשמור סיסמאות ב־Firestore, במסמכי תלמיד, בדוחות, בלוגים או בקוד.
- משתמש לא רשום רשאי לתרגל אך אינו אמור להיכלל בדוחות או במעקב המרכזי.
- מידע תלמיד נשמר רק תחת מזהה המשתמש שלו; הרשאות Firestore חייבות למנוע גישה של תלמיד לנתוני תלמיד אחר.
- גישת דשבורד כיתתית ומפתחות תשובות היא למנהל בלבד.
- אין לפרסם מפתחות, service accounts או סודות Firebase בריפו.
