# מערכת צירים — הרביע הראשון · LMS מתוקשב

`yanivmizrachiy/coordinate-lms` הוא הריפו של הגרסה **המתוקשבת**.

## מקור האמת

המסמך המחייב היחיד הוא:

> `RULES.md`

`README.md` מתאר את הפרויקט בלבד ואינו מגדיר כללים מתחרים.

## הקשר לחוברת להדפסה

- ריפו המקור להדפסה: `yanivmizrachiy/coordinate-first-quadrant`.
- ריפו ההדפסה הוא **קריאה בלבד** בזמן עבודת LMS.
- החוברת הקנונית הנוכחית כוללת **78 עמודים ממוספרים**.
- כל עמוד קנוני להדפסה חייב לקבל עמוד מתוקשב מקביל.
- הגרסה המתוקשבת מבוססת על אותו תוכן, אותן שאלות, אותם שרטוטים, אותו סדר ואותו עיצוב בסיסי של הדפים להדפסה.
- אין לשנות את דפי ההדפסה כדי להתאים אותם לתקשוב.
- אינטראקציה, בדיקת תשובות, משוב, הרשמה, שמירה ו-Firebase מתווספים רק בשכבת ה-LMS.

## עקרונות התקשוב

- משימה חזותית נשארת חזותית: למשל סימון נקודה נעשה בלחיצה/מגע ישירות על מערכת הצירים.
- כאשר יש הרבה תשובות נכונות, המערכת בודקת את **התנאי המתמטי** ולא תשובה יחידה שנכתבה מראש.
- שאלות מסוג „הסבר מדוע” מותאמות בדיגיטל למשימה אובייקטיבית שניתנת לבדיקה, בדרך כלל ארבע אפשרויות עם מסיחים דידקטיים חכמים, בלי לשנות את השאלה המודפסת.
- כל התאמה דיגיטלית חייבת לשמור על אותה מטרה מתמטית ורמת חשיבה.

## פיתוח ובדיקות

```bash
npm install
npm run dev
npm run answers:coverage:check
npm run typecheck
npm test
npm run test:firestore
npm run build
npm audit --audit-level=high
npm audit --omit=dev --audit-level=high
npm run firebase:check
npm run release:report
npm run test:visual
```

הבדיקות חייבות גם לזהות סטייה בין חוברת ההדפסה הקנונית לבין שכבת ה-LMS ולחסום שחרור במקרה של חוסר התאמה.
