# מערכת צירים — הרביע הראשון · LMS מתוקשב

הריפו של הגרסה המתוקשבת.

## מקור אמת

**המסמך המחייב היחיד הוא `RULES.md`.**

כל מסמך אחר בריפו הוא תיעוד, סטטוס או תוכנית עבודה בלבד ואינו רשאי להגדיר כלל שסותר את `RULES.md`.

## מראת מצב קנונית — לא מקור דרישות

החוברת שהקוד טוען כעת כוללת **78 עמודים ממוספרים**. כל 78 העמודים קיימים ברצף החוברת, והבדיקות דורשות התאמה לכל 78 העמודים. המספר כאן הוא מראת־סטטוס שנבדקת מול מודל החוברת; אם יש אי־התאמה, `RULES.md` ומודל החוברת הם הסמכות וה־CI חייב להיכשל.
