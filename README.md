# מערכת צירים — הרביע הראשון · LMS מתוקשב

הריפו של הגרסה המתוקשבת.

## מקור אמת

**המסמך המחייב היחיד ומקור האמת היחיד הוא `RULES.md`.**

כל מסמך, דוח, בדיקה, מודל קוד, סטטוס או תוכנית עבודה בריפו חייבים להתאים ל־`RULES.md` ואינם רשאים להגדיר דרישה עצמאית או סותרת.

## מראת מצב — לא מקור דרישות

הקוד הנוכחי טוען 78 עמודים ממוספרים. זהו נתון מצב בלבד. אם הקוד, המודל או כל מסמך אינם תואמים ל־`RULES.md` ולמקור ההדפסה הקנוני כפי שמוגדר בו, זו תקלה שיש לתקן וה־CI צריך לחסום פרסום.
